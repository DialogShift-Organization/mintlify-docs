---

The Smart Host Offer Agent collects offer requests directly in the chat and submits them to Smart Host. Your hotel can then process the request and create a suitable offer.

## Prerequisites

- Your hotel uses Smart Host.
- The Smart Host integration and Offer Agent are enabled for your DialogShift account.

## How it works

The Offer Agent starts when a guest selects **Request an offer** in the chat or explicitly asks for an offer.

During the conversation, the agent collects:

- arrival and departure dates
- occupancy for one or more rooms
- the preferred meal plan, depending on the configuration
- preferred room type
- name
- email address
- mobile phone number
- optional newsletter subscription

DialogShift then submits the offer request to Smart Host.

## After submission

Your hotel can process the request automatically or manually in Smart Host.

<Note>
  A submitted offer request is not yet a confirmed booking.
</Note>

You can view the progress of requests in the DialogShift app under **Statistics → Booking statistics → Offer requests**. For more information, see [Booking statistics](/en/statistics/booking-statistics).

To embed DialogShift Chat in a Smart Host offer, see [Embed Channels](/en/platform/embed-channels).
