Use Email AI functions directly in Mozilla Thunderbird for guest correspondence.

## Installation

<Steps>
  <Step title="Download plugin">
    Download the file:

    <Card title="Thunderbird Plugin v1.2.0" icon="envelope" href="https://assets.dialogshift.com/emailai/thunderbird/dialogshift_email_ai-1.2.0-tb.xpi">
      Download plugin
    </Card>
  </Step>

  <Step title="Open the Add-ons Manager">
    In Thunderbird, open the hamburger menu and select **Add-ons and Themes** (or **Tools → Add-ons and Themes**)

    ![Opening the Add-ons and Themes menu in Thunderbird](/images/email_ai/thunderbird_step_1.png)
  </Step>

  <Step title="Install from file">
    Click the gear icon next to the search box and select **Install Add-on From File…**, then choose the downloaded `.xpi` file

    Alternatively, drag the `.xpi` file directly onto the open Add-ons Manager tab.

    ![Installing an add-on from file in Thunderbird's Add-ons Manager](/images/email_ai/thunderbird_step_2.png)
  </Step>

  <Step title="Confirm permissions">
    Thunderbird shows the permissions the plugin requests — access to the dialogshift.com domain, reading and modifying email messages as you compose and send them, and access to browser tabs. Click **Add** to confirm.

    ![Confirming the plugin's permission prompt in Thunderbird](/images/email_ai/thunderbird_step_3.png)
  </Step>
</Steps>

The plugin is active immediately — no restart required.
