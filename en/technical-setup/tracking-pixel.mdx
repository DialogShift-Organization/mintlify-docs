---
title: 'Tracking Pixel'
description: 'Report completed bookings to DialogShift so conversions are attributed to the guest and the conversation.'
---

The tracking pixel reports completed bookings to DialogShift. You add it to the booking confirmation page – either as a pixel in the browser or as a direct call to the endpoint from your server.

## Endpoint

```
https://ibe.prod.co25.net/pixel?clientid=YOUR_CLIENT_ID&amount=234.56&currency=EUR&custid=GUEST_ID
```

## Parameters

| Parameter | Required | Description | Example |
| --- | --- | --- | --- |
| `clientid` | Required | Client ID provided by DialogShift | `pro123` |
| `amount` | Required | Booking amount, dot as decimal separator, no thousands separator | `234.56` |
| `currency` | Recommended | Currency code (ISO 4217); `EUR` is assumed if missing | `EUR` |
| `custid` | Recommended | Guest ID that DialogShift appended to the booking URL – return it unchanged | `c8f2a1` |
| `conversionType` | Optional | Default is `ibe` | `ibe` |
| `rooms` | Optional | Number of booked rooms | `2` |
| `nights` | Optional | Number of nights | `3` |
| `persons` | Optional | Number of persons | `4` |
| `url` | Optional | URL of the booking confirmation page | `https://...` |

## Guest attribution with `custid`

When DialogShift sends a guest into the booking flow, it appends a `custid` parameter to the URL (e.g. `…?…&custid=c8f2a1`). Read this value from the requested URL, keep it throughout the entire booking flow and return it as `custid` in the pixel call. DialogShift then attributes the booking exactly to this guest.

Without `custid`, attribution relies on fingerprinting and is much less accurate.

## Implementation

### Option A: Tracking pixel in the browser

Add a hidden image to the confirmation page. Insert the values from your booking:

```html
<script>
var pixel = document.createElement("img");
pixel.src = "https://ibe.prod.co25.net/pixel?clientid=YOUR_CLIENT_ID&amount=" + amount + "&currency=" + currency + "&custid=" + custid;
pixel.style = "display:none;";
document.body.appendChild(pixel);
</script>
```

You can also deliver this snippet via Google Tag Manager.

### Option B: Call the endpoint directly

Call the same URL server-side via `GET` as soon as the booking is confirmed:

```
GET https://ibe.prod.co25.net/pixel?clientid=YOUR_CLIENT_ID&amount=234.56&currency=EUR&custid=c8f2a1
```

<Note>
With a server-side call, DialogShift receives your server's IP, not the guest's. Therefore always include `custid` – otherwise DialogShift cannot attribute the booking.
</Note>
