title: "Smart Host Angebotsagent"
description: "So erfasst der Smart Host Angebotsagent im Chat Reise- und Kontaktdaten für eine Angebotsanfrage."
---

Der Smart Host Angebotsagent nimmt Angebotsanfragen direkt im Chat auf und übermittelt sie an Smart Host. Dort kann dein Hotel die Anfrage weiterbearbeiten und ein passendes Angebot erstellen.

## Voraussetzungen

- Dein Hotel nutzt Smart Host.
- Die Smart-Host-Integration und der Angebotsagent sind für dein DialogShift-Konto aktiviert.

## Funktionsweise

Der Angebotsagent startet, wenn ein Gast im Chat auf **Angebot anfordern** klickt oder ausdrücklich nach einem Angebot fragt.

Im Dialog erfasst der Agent:

- Anreise- und Abreisedatum
- Belegung für ein oder mehrere Zimmer
- je nach Konfiguration die gewünschte Verpflegung
- gewünschten Zimmertyp
- Name
- E-Mail-Adresse
- Mobilfunknummer
- optionales Newsletter-Abonnement

Anschließend übermittelt DialogShift die Angebotsanfrage an Smart Host.

## Nach dem Absenden

Die Anfrage kann in Smart Host automatisiert oder manuell durch dein Hotel weiterbearbeitet werden.

<Note>
  Eine abgesendete Angebotsanfrage ist noch keine verbindliche Buchung.
</Note>

Den Fortschritt der Anfragen findest du in der DialogShift App unter **Statistiken → Buchungsstatistik → Angebotsanfragen**. Weitere Informationen stehen im Artikel [Buchungsstatistik](/de/statistiken/buchungsstatistik).

Wie du den DialogShift Chat in ein Smart-Host-Angebot einbindest, erfährst du unter [Kanäle einbinden](/de/platform/kanaele-einbinden).
