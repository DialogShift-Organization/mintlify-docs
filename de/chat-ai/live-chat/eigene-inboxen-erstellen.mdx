---
title: "Eigene Inboxen erstellen"
description: "So erstellst du thematische Inboxen für die Live Chats eines oder mehrerer Hotels"
---

Mit eigenen Inboxen sortierst du Live Chats automatisch nach Themen wie Zimmerreservierung, Tischreservierung oder Spa. Eine Inbox kann die Live Chats mehrerer Hotels bündeln.

## Voraussetzungen

Du benötigst eine Admin-Rolle für die Organisation, eine Marke oder ein Hotel. Eigene Inboxen verwaltest du am Desktop.

## Eigene Inbox erstellen

1. Öffne in der linken Navigationsleiste **Organisation**.
2. Wähle **Eigene Inboxen**.
3. Klicke oben rechts auf **Eigene Inbox erstellen**.
4. Aktiviere die Inbox und fülle mindestens die Pflichtfelder **Name** und **Typ** aus.
5. Lege die weiteren Einstellungen fest.
6. Klicke auf **Speichern**.

![Einstellungen für eine eigene Inbox](/images/eigene-inbox-anlegen.png)

## Einstellungen

| Einstellung | Bedeutung |
| --- | --- |
| **aktiv** | Nur eine aktive Inbox sortiert neue Live Chats ein. |
| **Name** | Der Name, unter dem die Inbox im Live Chat erscheint. |
| **Typ** | Zur Auswahl stehen **Spa**, **Zimmerreservierung**, **Tischreservierung**, **Event** und **Eigene Inbox**. Die ersten vier Typen enthalten bereits passende Stichwörter und Blockerwörter. |
| **Chatbots** | Wähle das Hotel oder die Hotels aus, deren Live Chats in dieser Inbox gesammelt werden sollen. |
| **Verfügbarkeitszeiten** | Lege fest, wann dein Team für dieses Thema erreichbar ist. Ohne eingetragene Zeiten ist die Inbox rund um die Uhr verfügbar. |
| **Kanäle** | Wähle Kanäle aus, deren Live Chats immer in diese Inbox weitergeleitet werden sollen. |
| **Eigene Stichwörter** | Ergänze pro Sprache passende Wörter, getrennt durch Kommas. Erwähnt ein Gast eines dieser Wörter, kann der Live Chat dieser Inbox zugeordnet werden. |
| **Eigene Blockerwörter** | Ergänze pro Sprache Wörter, die eine Zuordnung zu dieser Inbox verhindern sollen. So vermeidest du thematische Fehlzuordnungen. |

<Note>
  Sobald du mindestens einen Kanal auswählst, entscheidet ausschließlich der Kanal über die Zuordnung. Die Stichwörter und Blockerwörter werden dann nicht berücksichtigt.
</Note>

Wenn du Verfügbarkeitszeiten einträgst, legt DialogShift für jedes ausgewählte Hotel automatisch eine Abwesenheitsnachricht an. Den Text kannst du über den Link unter der Chatbot-Auswahl bearbeiten.

## Inbox im Live Chat verwenden

Nach dem Speichern findest du die Inbox im Live Chat unter **Eigene Inboxen**. Du kannst einen Live Chat zusätzlich manuell über **Inbox zuweisen** einer oder mehreren Inboxen zuordnen.

Mehr zur Bearbeitung von Live Chats erfährst du unter [Live Chats beantworten](/de/chat-ai/live-chat/live-chats-beantworten).
